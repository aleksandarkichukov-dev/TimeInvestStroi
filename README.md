# Тайминвест Строй: нов сайт

Нов сайт за [timeinveststroy.com](https://www.timeinveststroy.com/), който заменя сегашния WordPress.
Съдържанието (текстове, услуги, проекти, снимки, партньори, контакти, политика за поверителност) е взето
от сегашния сайт. Нова информация не е добавена.

Next.js 16 (App Router), статично генериране, GSAP + Lenis за анимациите и View Transitions за преходите.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продукционна версия
npm run images     # обработва снимките от media-src/ → public/img/ и обновява манифеста
```

## Страници

| Адрес | Съдържание |
| --- | --- |
| `/` | слоган, „За нас“, етапите на строежа, услуги, проекти, преди/след, партньори, контакти |

| `/proekti` и `/proekti/<slug>` | 12-те проекта от галерията с всички снимки и лайтбокс |

| `/kontakti` | телефон, имейл, адрес и форма „Поискай оферта“ |
| `/politika-za-poveritelnost` | политиката от сегашния сайт, дословно |

## Дизайн

- **Цветове:** синьо и бяло. Тъмносиньо `#0c1b2e`, синьото от логото `#54b9ff`, наситено синьо
  `#1768c9` за бутоните, студено бяло `#f5f7fa`. Токените са в `src/app/globals.css`.
- **Шрифтове (с кирилица):** Unbounded за заглавията, Manrope за текста, JetBrains Mono за малките надписи.
- **Мотиви:** мрежа като милиметрова хартия, кóти, номерация 01 / 02 / 03, щамп на архитектурен лист в hero.
- **Ефекти:** чертеж на Лейк хаус, който при скрол се превръща в снимката; закована секция с хоризонтален скрол;
  снимки с „издигаща се“ маска; заглавия ред по ред; плъзгач преди/след; филтър на проектите с FLIP;
  лента с партньорите; магнитни бутони и курсор; завеса и „отлитаща“ снимка при смяна на страницата.
  При `prefers-reduced-motion` всичко се изключва.

### Нов проект

1. Сложете снимките в `media-src/projects/<slug>/`.
2. `npm run images`: създава WebP файловете в `public/img/projects/<slug>/` и обновява `src/content/images.json`.
3. Добавете запис в `src/content/projects.ts` със заглавие, корица и списък със снимките.

`media-src/` (оригиналите) не влиза в git. В git влизат само обработените снимки в `public/img/`.

## Форма „Поискай оферта“

`POST /api/oferta` изпраща запитването на `office@timeinveststroy.com` чрез SMTP. Защитата от ботове е
скрито поле-капан, минимално време за попълване и ограничение на заявките по IP. Копирайте `.env.example`
като `.env.local` (или задайте в хостинга) и попълнете `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER` и `SMTP_PASS`.

## SEO

- Отделна страница за всяка услуга и всеки проект, с мета описания и Open Graph снимки.
- Структурирани данни: `GeneralContractor`, `BreadcrumbList`, `Service`.
- `sitemap.xml` и `robots.txt` се генерират автоматично.
- 301 пренасочвания от всички стари адреси (`/services/`, `/gallery/`, `/privacy-policy`, 12-те страници на
  проекти, включително тези на кирилица) с един скок, чрез `src/proxy.ts`. Котвите `/#contacts` и `/#about-us`
  се пренасочват в браузъра.

## Публикуване

Нужен е хостинг с Node.js (например Vercel), защото пренасочванията, оптимизацията на снимките и формата
изискват сървър.
